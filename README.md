# educacao

MVP de engenharia de dados para explorar indicadores da Educação Básica
brasileira descritos pelo [QEdu](https://portaliede.org.br/qedu/).

## Status

O repositório está na etapa inicial de descoberta das fontes. A página
institucional consultada descreve indicadores como Ideb, aprendizado adequado
no Saeb, fluxo escolar e distorção idade-série, mas não publica um contrato
técnico de API. Nenhum endpoint ou formato de integração é presumido.

## Desenvolvimento

O projeto usa Poetry para dependências e ambiente. Consulte
[Desenvolvimento](docs/development.md) para os comandos de instalação e
validação e [Fontes de dados](docs/data-sources.md) para o estado da pesquisa.
